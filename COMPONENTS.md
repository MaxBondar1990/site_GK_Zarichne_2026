# ЖК «Заріччя»: структура реалізації

Візуальна основа — чотири аркуші в `design/` та `design/README.md`.

## Сторінки

- `src/index.html` — головна: перший екран, добірка квартир, про будинок, запис.
- `src/apartments.html` — каталог: кімнатність, діапазон площі, пагінація, мобільні фільтри.
- `src/apartment.html?id=01` — окреме планування, 2D/3D, можливе облаштування, інші квартири.
- `src/building.html` — будинок, переваги, характеристики, фотографії.
- `src/gallery.html` — категорії зображень і перегляд зі стрілками.
- `src/location.html` — розташування, категорії інфраструктури, карта.
- `src/documents.html` — окремі сторінки документів із переглядом оригіналів.
- `src/contacts.html` — контакти й демонстраційна форма.

## Компоненти збірки

Усі сторінки успадковують `src/components/templates/main/main.html` через `<template>` / `<block>`.
Секції підключені через `<include>`. Атрибут `data-fls-імʼя` запускає автоматичне підключення однойменного JS-модуля через наявний механізм збірки. Кожен модуль імпортує власний SCSS.

Компоненти лежать у `src/components/sections/`. Використано БЕМ: `catalog__grid`, `catalog--home`, `catalog__chip--active` тощо. Загальні кольори, типографіка, контейнер, кнопки та поля — у `src/styles/style.scss`. Спільний шаблон підключає цей файл через `main.scss`.

Дані планувань та генератор картки — `src/components/sections/catalog/_data.js`.
Старі `residence.css` і `residence.js` видалено; сторінки їх не використовують.

## Наповнення

Характеристики, поверхи, наявність та зіставлення площ із зображеннями потребують підтвердження. Контакти й переваги демонстраційні. Усі форми працюють локально, без надсилання або збереження даних. Окремих візуалізацій ремонту ще немає: вкладка «Інтерʼєр» показує наявний приклад меблювання з поясненням.

## Локальна робота

У терміналі проєкту: `nvm use`, потім `npm run dev -- --port 1112 --strictPort`.
Перевірка готової збірки: `npm run build`.
